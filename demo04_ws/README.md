# demo04_ws — TF exercises

Packages: `tf01_static`, `tf02_dynamic`, `tf03_tfs`, `tf04_test`.

Contains static/dynamic transform publishers and subscribers, transform-chain examples, and turtlesim coordination exercises. Source C++ and launch files are preserved. Regenerate the workspace top-level CMakeLists with `catkin_init_workspace`, then build with `catkin_make` in ROS Noetic.

Launch examples are under each package's `launch/` directory. This upload archives existing work; no new runtime validation is claimed.
