# demo05_ws — robot models and navigation

Packages: `urdf01_rviz`, `urdf02_gazebo`, `nav_demo`.

Contains URDF/Xacro robot models, RViz configurations, Gazebo launch/world files, sensor descriptions and navigation maps/configurations. Binary mesh and map assets required by these packages are included. External Gazebo models or installed ROS plugins may still be required.

Build instructions are in the repository root. Original parameters and local paths are retained for traceability; review them before execution. This upload does not certify navigation or real-hardware deployment.
